# Project Tutor — Voice Interactive Tutor

## Origin
Raj could not find a proper French tutor for his son in Bangalore. His son is in 10th standard, CBSE syllabus, and studies French as a subject. Raj wants to build a voice-interactive, LLM-powered tutor as a substitute/supplement, starting with French.

## Vision
- Phase 1: Audio-interactive French tutor for CBSE Grade 10 French — conversation practice, pronunciation, vocabulary, grammar, aligned to the CBSE French syllabus.
- Phase 2 (contingent on Phase 1 success): extend to other subjects.

## Tooling on hand
- Ollama installed locally, can pull additional models.
- Claude Code license — intended dev tool for building the application.
- Also has Claude Pro / Claude Desktop, and separately explores the Anthropic API.

## Status
Just starting — discussing feasibility before committing to architecture/tech stack.
